
🐾 쿠키월드 & Shopping Mall
프로젝트 소개


이 프로젝트는 반려견 용품 쇼핑몰과 함께 사용자 중심의 자유게시판, 구매 계획을 위한 버킷리스트 기능을 제공합니다.
사용자는 물품 추천 및 공유, 구매 계획 설정, 쇼핑 이력 확인과 같은 활동을 통해 보다 효율적으로 반려견 용품을 관리할 수 있습니다.
기술 스택: Java, MariaDB, Spring Framework, REST API, HTML/CSS/JavaScript, MySQL Workbench, Git

주요 내용:
- 자유게시판, 버킷리스트, 쇼핑몰 등 반려견 용품 관리 플랫폼 개발
- Java와 Spring을 활용한 백엔드 설계 및 구현
- MariaDB와 Workbench를 이용한 데이터베이스 설계 및 최적화
- REST API 설계를 통해 데이터 CRUD 기능 제공
  상세 내용: https://github.com/hyeran0510/shop
